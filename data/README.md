# data/

This folder is intentionally empty in the repository: child-level files are **not redistributed**.

Rebuild `cohorte_2012_2024.csv` here (6,688 rows; children aged 36-71 months in 2012 with both TVIP scores) from the public ELPI microdata, following the variable definitions in `../docs/diccionario_cohorte.csv`.

ELPI microdata, questionnaires and manuals (Observatorio Social, Ministerio de Desarrollo Social y Familia):
- 2012, second round: https://observatorio.ministeriodesarrollosocial.gob.cl/elpi-segunda-ronda
- 2024, fourth round: https://observatorio.ministeriodesarrollosocial.gob.cl/elpi-cuarta-ronda
